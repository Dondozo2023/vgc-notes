アーニャ氏が**グローバルチャレンジ2027第1回予選で21勝0敗、最終レート1821.820、最終30位**を記録し、予選を通過した構築である。メガガブリアスZとコータスを先発に置き、いのちのたまオオニューラときあいのタスキイダイトウで試合を締める。イエッサン構築には、ドリュウズとバンギラスを使う別の選出を用意している。

本文は[アーニャ氏の「全勝予選抜けメガガブリアスZ」](https://note.com/spy_anya/n/ne2bff802e478)と提供されたチーム画像をもとに、勝ち方と使い方を整理した。チームIDは **K36EYDHL72** である。

## 構築コンセプト

**メガガブリアスZが相手の主力を上から攻撃し、コータスがもう一方へあくびを入れる。相手の交代にはあくびを重ね、居座りには眠りとイダイトウのおはかまいりで対応する。** 晴れによる火力補助と、後発2匹の処理能力を組み合わせた構築である。

コータスのひでりは、メガガブリアスZのかえんほうしゃを強化する。従来は味方のてだすけが必要だった火力を晴れで確保できるため、コータスは攻撃補助に1ターンを使わず、あくびやふんかを選べる。原文の「てだすけ火炎放射」は、この火力補助を比較した表現である。

あくびを受けた相手が交代すると、こちらはその交代先にもあくびを入れて展開を制限する。相手が居座って攻撃し、ガブリアスやコータスが倒された場合は、眠った相手に後発イダイトウを合わせる。味方のひんしで威力が上がったおはかまいりを通し、きあいのタスキで行動機会を残す。

オオニューラは、この展開を抜け出しやすいガオガエン・ゴリランダーや、先発2匹が苦手なフェアリー・高耐久の水タイプを処理する。いのちのたまによって攻撃範囲を広げ、相手が1匹眠った盤面では、起きているもう1匹を上から倒す役割を担う。

## 基本選出と動かし方

### 晴れとあくびから後発を通す

{{< selection lead="garchomp,torkoal" back="sneasler,basculegion" >}}

初手はガブリアスをZへメガシンカさせ、コータスの晴れを利用して攻める。メガガブリアスZが先に攻撃して倒せる相手を選び、コータスはその隣にあくびを入れる。鋼タイプには晴れかえんほうしゃ、ドラゴンにはりゅうのはどう、ペリッパーにはパワージェムを使う。

中盤の要点は、あくびを入れた相手の位置へ、翌ターンもあくびを選ぶことである。交代された場合は交代先が眠りの対象になる。相手が居座った場合は、先に入れたあくびによる眠りを狙う。同じ個体への2回目のあくびで眠りを早める動きではなく、交代先にも圧力をかける選択である。

先発が倒されたら、後発イダイトウのおはかまいりで反撃する。オオニューラは、眠っていない相手や、あくびを交代でかわすガオガエン・ゴリランダーを処理する。ガブリアスを安全にオオニューラへ交代できる盤面では、先発を失う前に後発の火力を使う。

選出時には、相手の6匹からガブリアス＋コータスで対応できない先発があるかを考える。著者はこれを基本選出を変える判断基準としている。

### イエッサンには砂ドリュウズを使う

{{< selection lead="garchomp,excadrill" back="tyranitar,basculegion" >}}

イエッサン構築には、コータスとオオニューラに代えてドリュウズとバンギラスを選出する。サイコシードで特防を上げたオオニューラを、物理攻撃のドリュウズで処理する方針である。ドリュウズの鋼タイプは、イエッサン構築のワイドフォースなどのエスパー打点にも強い。

ドリュウズはヨプのみでオオニューラのインファイトを耐え、じしんで攻撃する。隣のガブリアスは、Zへメガシンカするとふゆうになり、味方のじしんを受けない。後発バンギラスのすなおこしで砂を展開し、ドリュウズのすなかきを利用する。

イダイトウは、この選出でも終盤の処理役である。バンギラスはイトケのみを持ち、相手のイダイトウの水打点への耐性を補う。

## メジャーな構築への選出

### ペリッパー＋ブリジュラスを中心とした雨構築

{{< selection lead="garchomp,torkoal" back="sneasler,basculegion" >}}

雨相手も基本選出を使う。コータスは序盤に相手の水タイプへあくびを入れ、メガガブリアスZはペリッパーへパワージェムを撃つ。ブリジュラスは序盤に無理に削らず、後発オオニューラのいのちのたまインファイトで一撃突破を狙う。相手の水タイプは、最後にイダイトウのおはかまいりで処理する。

ペリッパーに対する著者の処理方針は、次のとおりである。

| 想定するペリッパー | メガガブリアスZを中心とした処理方針 |
|---|---|
| こだわりスカーフ・特攻と素早さに配分 | 先にパワージェムを撃ち、一撃で倒す |
| きあいのタスキ／しめったいわ | パワージェムで削り、イダイトウのアクアジェットと合わせて処理する。追い風の残りターンも消費させる |
| オボンのみ・耐久に配分 | 追い風下でもメガガブリアスZより遅い型を想定し、パワージェムを2回当てる |

ペリッパーへパワージェムを選ぶことで、相手の天候役を削りながら後発の処理につなげる。上の行動順は著者が想定する配分を前提としており、持ち物だけで決まるものではない。

### ガオガエン・ゴリランダー入りスタン

{{< selection lead="garchomp,torkoal" back="sneasler,basculegion" >}}

この対面では、ガオガエンやゴリランダー自身よりも、その隣のポケモンをメガガブリアスZが倒せるかを見る。

**隣をメガガブリアスZが上から倒せるなら、ガブリアスはその相手を攻撃し、コータスはふんかを撃つ。** 相手の攻撃役を処理しながら、ガオガエン・ゴリランダーや交代先も削る。

**隣を倒せないなら、コータスはその相手へあくびを入れる。** ガブリアスをオオニューラへ交代できる状況では、積極的に交代して後発の打点を使う。

ガオガエンには炎技が半減されるが、ふんかやウェザーボールの削りにも意味がある。著者の計算では、防御実数値143を想定したガオガエンに対し、攻撃1段階下降の珠オオニューラのインファイトは74.7〜88.6%入る。先に削っておけば、いかくを受けたオオニューラでも倒しやすい。

初手のふんかは、ガオガエンのすてゼリフに対して交代先も削る圧力となる。終盤は珠インファイト、あるいは晴れが切れた後のイダイトウのアクアブレイクで処理する。あくびだけに頼らず、後発の攻撃圏内まで削ることが重要である。

### イエッサン入り構築

{{< selection lead="garchomp,excadrill" back="tyranitar,basculegion" >}}

イエッサンの性別を問わず、この4匹を基本とする。サイコシードで特防が上がるオオニューラにはドリュウズの物理攻撃を、エスパー打点にはドリュウズの耐性とバンギラスを利用する。

イエッサン♂は自身のワイドフォースとこだわりスカーフ型、イエッサン♀はこのゆびとまれによる味方の保護を意識する。単体技と全体技のじしんを持つドリュウズを、ふゆうのメガガブリアスZと並べて使う。原記事は♂・♀それぞれの初手行動を固定していないため、ここでは選出と採用目的を示す。

### フラエッテ先発を警戒する場合

フラエッテを初手に出される可能性がある相手には、**オオニューラ＋コータス先発**を選ぶ。著者は予選の1試合でこの先発を使った。

オオニューラの毒打点で、ガブリアスが攻めにくいフェアリーへ圧力をかける選択である。この例の後発2匹は資料に示されていないため、固定選出としては記載しない。

## 個別解説

実数値・能力ポイントは **HP／攻撃／防御／特攻／特防／素早さ** の順である。画像の配分は各個体合計66ポイント。ガブリアスの画像実数値は通常時の値である。

### メガガブリアスZ

{{< pokemon "garchomp" >}}

- **性格・持ち物**：ひかえめ／ガブリアスナイトZ
- **特性**：通常時さめはだ／メガシンカ後ふゆう
- **技**：りゅうのはどう／かえんほうしゃ／パワージェム／まもる
- **通常時の実数値**：183 / 135 / 117 / 145 / 105 / 154
- **能力ポイント**：0 / 0 / 2 / 32 / 0 / 32

基本選出の先発アタッカーである。ドラゴン同士の対面を素早さとりゅうのはどうで制し、鋼タイプにはコータスの晴れで強化したかえんほうしゃを使う。パワージェムはペリッパーへの処理ルートを作る。

著者は、追い風を軸にしたフラエッテ・ニンフィアがM-Cで動きにくくなり、ドラゴンを通しやすいと評価した。すでに採用していたコータスで氷タイプに対応できるため、ドラゴン同士の対面に強いメガガブリアスZを選んだ。

防御2ポイントは、攻撃実数値200のガブリアスのドラゴンクローを50%で耐えるための調整である。著者によれば、防御無振りでは68.7%で倒される。

- **性格・持ち物**：ずぶとい／オボンのみ
- **特性**：ひでり
- **技**：ふんか／ウェザーボール／あくび／まもる

最初に採用された構築の起点である。ゴリランダーに強く、相手のトリックルーム下でも動きやすく、雨から天候を奪えることを評価した。晴れでガブリアスの火力を補いながら、あくびで相手の交代と居座りの両方に圧力をかける。

ふんかは相手2匹や交代先を削る技、晴れウェザーボールは単体を倒す打点である。ガオガエンにも削りを入れ、後発オオニューラとイダイトウの攻撃につなぐ。

耐久は、ようきヒスイウインディのもろはのずつきを93.7%で耐える。ひかえめメガボーマンダのダブルダメージのハイパーボイスは、オボンのみ込みで確定2回耐える。特攻はHP実数値189のサーフゴーを晴れウェザーボールで確定1発にする調整である。

きあいのタスキは、後発から一度行動するための持ち物である。アクアジェットは、パワージェムで削ったペリッパーなどの処理に使う。晴れが切れた後は、アクアブレイクでガオガエンを倒すルートもある。

### オオニューラ

- **性格・持ち物**：ようき／いのちのたま
- **特性**：どくしゅ

フェアリー、ガオガエン、ゴリランダー、雨下のブリジュラスを処理する補完枠である。環境考察で警戒したシード＋かるわざ型とは異なり、採用個体はどくしゅ＋いのちのたま。毒技もフェイタルクローではなく、どくづきを採用している。

いのちのたまは、通常のフェイタルクローを耐えるフェアリーやゴリランダー、いじっぱりオオニューラのインファイトを耐えるブリジュラスの耐久調整を越える火力を狙った持ち物である。ミロカロスやニョロトノのような特防の高い水タイプにも、物理のインファイトで攻める。

あくびで1匹を眠らせたら、起きているもう1匹を素早さ189と珠火力で倒す。メガボーマンダには、オオニューラのがんせきふうじからイダイトウのおはかまいりへつなぐ処理も想定しており、このルートのために最速を採用した。

イトケのみは、イエッサン構築に入るイダイトウへの対策である。いじっぱり珠イダイトウのウェーブタックルを、イトケのみ込みで確定耐えする。砂嵐下では、おくびょうフラエッテのムーンフォースを93.8%で耐える。

## 構築経緯と環境への対応

### コータスから始めた6匹

著者はM-BからM-Cへの移行で、ゴリランダー・イエッサンとフィールド対応のシードが加わったことを重視した。こだわりハチマキ・こだわりメガネが未解禁の当時、シードで能力を上げ、その消費でかるわざを発動するオオニューラを強い要素と考えた。

当時の環境を、ゴリランダー入り、イエッサン入り、雨の3系統として整理した。ゴリランダー＋グラスシードオオニューラは防御、イエッサン＋サイコシードオオニューラは特防が上がる。この違いを踏まえて、まずコータスを採用した。

次に、複数のねこだまし要員やトリックルームによって追い風軸が使いにくくなり、フラエッテ・ニンフィアの立場も悪くなると判断した。そこで、コータスが苦手なドラゴンへ打点を持ち、晴れの火力補助を受けられるメガガブリアスZを2匹目に置いた。

3匹目はあくび展開と噛み合うタスキイダイトウ、4匹目はフェアリー・交代であくびをかわす相手・雨への珠オオニューラである。この4匹ではイエッサン構築に勝てなかったため、5匹目にヨプドリュウズ、6匹目にイトケバンギラスを加えた。

採用順は、**コータス → メガガブリアスZ → イダイトウ → オオニューラ → ドリュウズ → バンギラス**。ガブリアスを先に置いて補完した構築ではなく、環境に刺さるコータスから、晴れとあくびを使う攻撃の形へ発展させた構築である。

### 砂の並びが生んだ選出誘導

イエッサン対策で加えたバンギラス＋ドリュウズは、基本選出にも副次的な効果を生んだ。著者によれば、相手のゴリランダー、ドドゲザン、サーフゴー、メガグソクムシャが先発に出てくることが増えた。いずれもコータスで攻めやすい相手であり、晴れ選出が通りやすくなった。

さらに、バンギラスの存在によってイダイトウのきあいのタスキが警戒されにくくなり、その1回の行動で競り勝った試合もあったという。コータスの環境適性、ガブリアス＋コータスの初手、珠オオニューラの火力に、この選出誘導と持ち物の誤認が重なったことを、著者は全勝の理由として振り返っている。

### 着想から大会投入まで

着想は9月18日、完成は翌19日である。完成後は本番まで構築を伏せ、使用したのは最後のランクマッチ数戦とGCの21試合だった。研究期間が短く、主要選出を2つに絞れたことから、著者は各要素を使った改良の余地も大きいと考えている。

## 著者が挙げた5つの発展案

以下は完成構築をもとにした研究案であり、別版の大会使用実績ではない。

1. トリックルームを覚えるポケモンを採用し、コータスをトリックルームエースに見せながら、ガブリアスZ＋コータスの先発を通す。
2. コータスの環境適性を評価し、トリックルーム＋コータスを素直に組む。
3. あくびとの相性から選んだイダイトウを含め、3匹目以降の採用を見直す。
4. フェアリーを強く使いにくい環境が続くという見通しから、メガガブリアスZを起点に組み直す。
