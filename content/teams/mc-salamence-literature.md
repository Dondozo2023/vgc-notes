すいか/SがGC2027 Iで1位を獲得した構築である。**KBSはドドゲザン・イダイトウ・オオニューラの略**。ボーマンダ・フラエッテ・ゴリランダーと組み合わせた6匹である。

原案はりこ氏の[「宇宙一かっこいいボーマンダ構築」](https://note.com/pokeu_tan/n/n807295ca8ff7)。本文は原案のコンセプト・選出・個体を基準とし、末尾でNewcon版とすいか/S版の変更を解説する。

## 構築コンセプト

**オオニューラとゴリランダーのねこだましでメガボーマンダの行動を確保し、ボーマンダ自身の追い風からハイパーボイスで相手を削る。ボーマンダを通しにくい相手には、瞑想メガフラエッテで勝つ。** この二つが構築の軸である。

ボーマンダは、命中が安定する全体技のハイパーボイスと、高い耐久を両立できる。オオニューラのねこだましで相手を止め、ボーマンダが追い風を展開する。ボーマンダが苦手なドドゲザンやフラエッテには、オオニューラの格闘・毒打点で圧力をかける。

さらに、ドドゲザンのふいうちとゴリランダーのグラススライダーで、ハイパーボイスで削った相手を倒しきる。ボーマンダの威嚇とゴリランダーのグラスフィールド回復で味方を残し、攻撃できる回数を増やす。

ペリッパー＋ブリジュラスやドラゴン軸には、メガフラエッテを攻撃役に据える。オオニューラとゴリランダーのねこだまし、通常ボーマンダの威嚇でフラエッテが瞑想を積む時間を作り、ムーンフォースで相手の中心を倒す方針である。

イダイトウは、この二つの展開を補う削り役・終盤の処理役である。相手のオオニューラを倒してフラエッテを動かしやすくするほか、追い風下のおはかまいりやアクアジェットで試合を締める。

## 基本選出と動かし方

### ボーマンダを通す

{{< selection lead="salamence,sneasler" back="kingambit,rillaboom" >}}

この4体は原案で選出の中心となった組み合わせである。先発ボーマンダ＋オオニューラから追い風を展開する。先発・後発は相手に応じて入れ替える。

ボーマンダとオオニューラを並べたら、オオニューラのねこだましで相手を止め、ボーマンダが追い風を展開する。その後、ボーマンダのハイパーボイスとオオニューラの攻撃で削る。鋼タイプにはかえんほうしゃ、ドドゲザンやフラエッテにはオオニューラの打点を通す。

相手の先発にライチュウやサーフゴーを予想する場合は、ゴリランダーやドドゲザンを先に出し、ボーマンダを後ろに置く選出も使う。後発ボーマンダで威嚇を入れ、追い風を張ってから攻め直せるのが強みである。

終盤は、ゴリランダーのグラススライダーやドドゲザンのふいうちで、削れた相手を処理する。イダイトウの攻撃が通りやすい相手には4体のうち1体を入れ替え、おはかまいりで詰める展開を選ぶ。

### フラエッテを通す

{{< selection lead="floette-eternal,rillaboom" back="sneasler,salamence" >}}

雨グソクに対する選出である。先発ゴリランダーのねこだましで相手を止め、フラエッテが瞑想を積む。ゴリランダーのフィールド回復でHPを保ち、相手の物理攻撃には通常ボーマンダの威嚇を合わせる。

フラエッテは瞑想で火力を上げ、ムーンフォースで相手の主力を倒す。ブリジュラスには、瞑想後のムーンフォースによる早期処理を狙う。

グソクムシャが場にいるときは、通常ボーマンダの威嚇と、オオニューラ・ゴリランダーのねこだましで行動を抑え、その隣をフラエッテで倒していく動きを基本とする。オオニューラが重い相手にはイダイトウを合わせ、先に処理してからフラエッテを通す。

## メジャーな構築への選出

{{< selection lead="rillaboom,kingambit" back="salamence,basculegion" >}}

ふいうちとグラススライダーでライチュウへ圧力をかけ、後発の追い風からイダイトウを通す。

相手には電気技が通りやすく見えるため、ライチュウから入ってくることが多い対面である。ボーマンダを警戒したミロカロス先発にも、ゴリランダーで対応できる。

ヒスイウインディを先発に出されたら、どちらかをボーマンダへ交代して威嚇を入れる。初手の2体を残しながら盤面を整え、最後は追い風下のイダイトウで詰める。

### 雨グソク：五分

{{< selection lead="floette-eternal,rillaboom" back="sneasler,salamence" >}}

ゴリランダー・オオニューラのねこだましとボーマンダの威嚇でフラエッテを支え、瞑想から雨の攻撃役を突破する。

ペリッパー＋ブリジュラスから入られたら、ゴリランダーがペリッパーへねこだましを撃ち、フラエッテが瞑想を積む。ゴリランダーとペリッパーの特性発動順から、素早さ関係も確認する。

グソクムシャ先発には、通常ボーマンダの威嚇を入れ、かえんほうしゃとムーンフォースを合わせる。あるいはオオニューラとゴリランダーのねこだましを使い回し、グソクムシャを止めながら隣を倒していく。

### 晴れ＋雨：不利

リザードン＋フシギバナへ耐性を持つボーマンダで入り、かえんほうしゃでフシギバナをアクアジェット圏内まで削る。ボーマンダが眠ったら、オオニューラのねこだましとタスキで眠りターンを稼ぐ。

フシギバナの処理と、途中のブリジュラスへの交代読みが必要なため、難しい対面である。晴れ側を乗り切った後、瞑想フラエッテを残して雨側へ対応する。

### イエッサン＋サーナイト：有利

{{< opponent pokemon="gardevoir,indeedee-f,armarouge,salamence,garchomp,sneasler" >}}

{{< selection lead="basculegion,kingambit" back="rillaboom,salamence" >}}

イエッサンを早く倒し、ゴリランダーでフィールドを取ることが目標である。

- **イエッサン＋グレンアルマ**なら、イダイトウで攻撃し、ドドゲザンをボーマンダへ交代する。
- **イエッサン＋サーナイト**なら、ドドゲザンで攻撃し、イダイトウをゴリランダーへ交代する。

相手の攻撃役に合わせて受け先を変え、フィールドを取り直し、ゴリランダーのねこだましやグラススライダー、ドドゲザンのふいうちを使える盤面を作る。

### 雨滅び：不利

{{< opponent pokemon="gengar,kommo-o,incineroar,rillaboom,swampert,politoed" >}}

{{< selection lead="kingambit,sneasler" back="floette-eternal,basculegion" >}}

ドドゲザンでゲンガーへ圧力をかけ、オオニューラでガオガエン・ゴリランダーを攻撃する。ジャラランガにはフラエッテを残す。

防音ジャラランガを想定すると、ボーマンダのハイパーボイスが通らず、滅びのうたでも処理されない。フェアリー4倍弱点を突けるフラエッテを選ぶ理由になる。

メガゲンガーのかげふみで交代を制限されると、ジャラランガに積む時間を与えてしまう。ドドゲザンのアイアンヘッドとオオニューラのインファイトを集中させるなど、相手に自由な準備時間を与えない立ち回りを目指す。

見せ合いのゴリランダーがニョロトノ＋ラグラージを牽制するため、著者は相手の雨選出が少ないと見ている。

### 砂サイコ＋アーマーガア：有利

この構築はアーマーガアへの有効打が限られるため、りこ氏は相手の先発アーマーガアを想定した。ボーマンダのかえんほうしゃで処理を進め、ドドゲザンで相手のバンギラス・ドリュウズ・ボーマンダを牽制する。

### プテラ・リザードン・ニンフィア：有利

{{< opponent pokemon="aerodactyl,charizard,kingambit,garchomp,sylveon,farigiraf" >}}

{{< selection lead="sneasler,kingambit" back="salamence,basculegion" >}}

りこ氏は相手の後発にリザードン・ガブリアス・ニンフィアを想定した。ただし、リキキリンを選出されたときは、トリックルーム下でニンフィアが攻撃できる並びを作らせないことを重視する。

バクーダには、ゴリランダーでフィールドを取りながらイダイトウのアクアジェットで圧力をかける。

サーフゴーは後発ドドゲザンで対応し、オオニューラで終盤を処理する。

{{< selection lead="floette-eternal,sneasler" back="rillaboom,unknown" >}}

ライチュウXのアンコールを受けた場合も、瞑想を積み進める方針である。解除されるターンにゴリランダーかオオニューラのねこだましを合わせ、フラエッテが攻撃へ移り、積み回数の優位を使って突破する。

## 個別解説

実数値・能力ポイントはHP／攻撃／防御／特攻／特防／素早さの順である。ここではりこ原案の型を紹介する。

### ボーマンダ

{{< pokemon "salamence" >}}

- **持ち物・特性・性格**：ボーマンダナイト／いかく（メガ後はスカイスキン）／ひかえめ
- **技**：ハイパーボイス／かえんほうしゃ／おいかぜ／まもる
- **通常時の実数値**：183 / 139 / 100 / 159 / 120 / 138
- **メガ後の実数値**：183 / 148 / 150 / 170 / 130 / 158
- **能力ポイント**：13 / 0 / 0 / 15 / 20 / 18

ボーマンダは構築の主軸である。最速ヒスイウインディを上回るS158を確保し、残りは火力と耐久に回している。追い風を張るだけでなく、攻撃を受けながらハイパーボイスを複数回撃つための調整である。

かえんほうしゃは、ドドゲザン・サーフゴー・アーマーガアなどへの打点である。ねっぷうより命中が安定し、狙った相手を集中して削れる。りこ氏は、グラスフィールドの回復込みでもドドゲザンを2発で倒す火力を目安に配分した。

フラエッテをメガシンカさせる試合では、通常のまま威嚇と追い風で支援する。天候構築やグソクムシャ入りに対して、フラエッテと一緒に選出する役割である。

### オオニューラ

{{< pokemon "sneasler" >}}

- **持ち物・特性・性格**：きあいのタスキ／どくしゅ／ようき
- **技**：インファイト／どくづき／ねこだまし／まもる
- **実数値**：155 / 182 / 82 / 54 / 100 / 189
- **能力ポイント**：0 / 32 / 2 / 0 / 0 / 32

ボーマンダが誘うドドゲザン・フラエッテ・ニンフィアに圧力をかける枠である。初手ではオオニューラのねこだましでボーマンダの追い風やフラエッテの瞑想を助け、後発では素早さと打点で相手を処理する。

りこ氏は毒の追加ダメージで相手を倒せる範囲を広げるため、原案ではどくづきを採用した。Newcon氏・すいか氏・リンヤ氏はアレンジ版でフェイタルクローへ変更した。

### ドドゲザン

{{< pokemon "kingambit" >}}

- **持ち物・特性・性格**：ヨプのみ／まけんき／いじっぱり
- **技**：ドゲザン／ふいうち／アイアンヘッド／けたぐり
- **実数値**：207 / 198 / 140 / 72 / 105 / 79
- **能力ポイント**：32 / 25 / 0 / 0 / 0 / 9

ゲンガー・サーフゴー・ボーマンダミラーを担当し、ドラゴン技への交代先にもなる。アイアンヘッドは、ボーマンダが苦手なフラエッテやニンフィアへの打点である。

ヨプのみで格闘技を耐えても、その後の先制技まで受けきる余裕が小さい場合がある。ボーマンダの威嚇を合わせてHPを残し、場に居続けて圧力をかける。

原案のけたぐりはドドゲザンミラーとバンギラスへの打点である。特に、追い風下でバンギラスを処理するルートを確保している。

### ゴリランダー

{{< pokemon "rillaboom" >}}

- **持ち物・特性・性格**：きせきのタネ／グラスメイカー／いじっぱり
- **技**：ウッドハンマー／グラススライダー／10まんばりき／ねこだまし
- **実数値**：207 / 167 / 115 / 72 / 112 / 105
- **能力ポイント**：32 / 7 / 5 / 0 / 22 / 0

ゴリランダーは、ねこだまし、フィールドの上書き、グラススライダー、回復を一枠で担う。原案ではイエッサン＋サーナイトやブリジュラスへ後投げすることを考え、HPと特防を厚くしている。

ボーマンダを警戒して出てくるミロカロスにはウッドハンマー、キラフロルには追い風下の10まんばりきを通す。メガライチュウYには、グラススライダーとドドゲザンのふいうちを合わせる。

グラスフィールドの回復は、ドレインキッスを持たないフラエッテのHP管理にも役立つ。

### フラエッテ

{{< pokemon "floette-eternal" >}}

- **持ち物・特性・性格**：フラエッテナイト／フラワーベール（メガ後はフェアリーオーラ）／ひかえめ
- **技**：ムーンフォース／マジカルシャイン／めいそう／まもる
- **通常時の実数値**：177 / 76 / 104 / 165 / 148 / 128
- **メガ後の実数値**：177 / 94 / 124 / 198 / 168 / 138
- **能力ポイント**：28 / 0 / 17 / 5 / 0 / 16

フラエッテは、ボーマンダでは対応しにくいペリッパー＋ブリジュラス・ガブリアスZ・ジャラランガを担当する第二のメガ枠である。オオニューラ・ゴリランダーのねこだましとボーマンダの威嚇で支え、フラエッテが瞑想を積んでから高火力のフェアリー技で突破する。

ムーンフォースを選んだ理由は、瞑想1回からブリジュラスを一撃で倒す火力を重視したためである。ドレインキッスで回復しながら何度も攻撃するより、相手を早く倒して被弾回数を減らすことを狙っている。

物理防御も厚く、くろたま山決勝ではグソクムシャのふいうちとオオニューラのフェイタルクローを耐えて勝利に貢献した。回復はゴリランダーのフィールドで補う。

### イダイトウ♂

{{< pokemon "basculegion" >}}

- **持ち物・特性・性格**：カシブのみ／てきおうりょく／いじっぱり
- **技**：ウェーブタックル／おはかまいり／アクアジェット／まもる
- **実数値**：205 / 165 / 100 / 90 / 102 / 114
- **能力ポイント**：10 / 18 / 15 / 0 / 7 / 16

序盤は耐久を使ってウェーブタックルで削り、終盤はおはかまいりとアクアジェットで処理する。ゴーストタイプのため、相手のねこだましを受けずに攻撃できる。追い風下でも安定して動く。

フラエッテを狙うオオニューラに強く、リザードン・グレンアルマ・バクーダなどにも打点を持つ。ヒスイウインディには、アクアジェットとボーマンダのハイパーボイスを合わせる動きも使う。

原案のカシブのみはゴースト技への耐久を補う持ち物である。アレンジ版ではナモのみとなり、ドドゲザンやグソクムシャの前でも攻撃しやすくなった。著者も、最終的にはナモのみを推奨している。

## 構築経緯と環境への対応

りこ氏は命中不安を減らし、耐久に寄せて不利な乱数に負けにくい構築を目指した。そこで、新環境で追加されたメガボーマンダに着目し、命中が安定する高火力全体技、高い耐久と素早さ、グソクムシャへの強さを評価して採用した。

りこ氏はハイパーボイス・おいかぜ・まもるを先に決め、残る1枠を比較した。りゅうせいぐんは同速勝負と命中不安、すてみタックルは反動、ねっぷうは命中不安と対ドドゲザンの火力を理由に採用を見送った。これらの課題を避ける技として、かえんほうしゃを採用した。

### 苦手な相手を補完する

まず、りこ氏はボーマンダが苦手なフェアリー・鋼へ打点を持つオオニューラを採用した。オオニューラのねこだましで、ボーマンダが追い風を使う時間も確保した。

次に、イエッサン＋サーナイト・サーフゴー・メガライチュウYへの対策として、ドドゲザンとゴリランダーを追加した。この2体がゴースト・エスパーへの打点、サイコフィールドの解除、先制技、回復を補い、ボーマンダを中心とする4体が成立した。

残る課題はペリッパー＋ブリジュラスとドラゴン軸への対応だった。りこ氏は瞑想フラエッテを追加し、オオニューラ・ゴリランダーのねこだましとグラスフィールドの回復を使う第二の勝ち筋を確保した。

最後に、フラエッテ選出で重くなるオオニューラとウルガモス、晴れ構築・バクーダ・バンギラス＋ドリュウズへの対策としてイダイトウを採用し、6体が完成した。

## Brisbane・GC向けのアレンジ

### 技と持ち物の変更

Newcon氏・すいか氏・リンヤ氏は、BrisbaneのOTS環境を想定して原案を調整した。

| ポケモン | 原案 | アレンジ版 |
|---|---|---|
| オオニューラ | どくづき | フェイタルクロー |
| ドドゲザン | けたぐり | まもる |
| イダイトウ♂ | カシブのみ | ナモのみ |

3氏はサイコフィールドとトリックルームが多いと予想し、ドドゲザンのけたぐりをまもるへ変更した。相手のねこだましと攻撃の集中を防ぎ、サイコフィールドとトリックルームの残りターンを消費するためである。

けたぐりを失ったことで相手ドドゲザンへの対応が減る分は、ナモのみイダイトウで補う。3氏はゲンガーの減少とバンギラス＋ドリュウズの採用を予想し、この変更を採用した。

例えば相手がオオニューラ＋ドドゲザンを並べた場面でも、ナモのみがあればイダイトウでオオニューラを攻撃しやすくなる。フラエッテを通すための処理役としても動かしやすくなる変更である。

### 火力と行動順を調整する

3氏はゴリランダーの耐久を削り、攻撃実数値を187へ引き上げた。グラススライダーと10まんばりきで倒せる範囲を広げた。

素早さはイダイトウより1低くしている。持久力ブリジュラスに対し、おはかまいりを先に当てて大きく削り、防御が上がった後に10まんばりきを当てる順序を作るためである。

すいか/S版では、この順序を保ったまま両方を準速ペリッパーより速くしている。

| ポケモン | Newcon版のS | すいか/S版のS |
|---|---:|---:|
| イダイトウ♂ | 114 | 119 |
| ゴリランダー | 113 | 118 |

ドドゲザンはS70の遅めの調整となり、まもると合わせてトリルへの対応を強めている。一方、原案のけたぐりにもバンギラスやドドゲザンミラーを処理する役割があり、著者たちは大会環境に応じて技を選んでいる。
