すいか/SがGC2027 Iで1位を獲得した構築です。**KBSはドドゲザン・イダイトウ・オオニューラの略**。ボーマンダ・フラエッテ・ゴリランダーと組み合わせた6匹です。

原案はりこ氏の[「宇宙一かっこいいボーマンダ構築」](https://note.com/pokeu_tan/n/n807295ca8ff7)。本文では原案のコンセプト・選出・個体を紹介し、末尾でNewcon版とすいか/S版への変更を解説します。

## 構築コンセプト

**オオニューラとゴリランダーのねこだましでメガボーマンダの行動を確保し、ボーマンダ自身の追い風からハイパーボイスで相手を削る。ボーマンダを通しにくい相手には、瞑想メガフラエッテで勝つ。** この二つが構築の軸です。

ボーマンダは、命中が安定する全体技のハイパーボイスと、高い耐久を両立できます。オオニューラのねこだましで相手を止め、ボーマンダが追い風を展開します。ボーマンダが苦手なドドゲザンやフラエッテには、オオニューラの格闘・毒打点で圧力をかけます。

さらに、ドドゲザンのふいうちとゴリランダーのグラススライダーで、ハイパーボイスで削った相手を倒しきります。ボーマンダの威嚇とゴリランダーのグラスフィールド回復で味方を残し、攻撃できる回数を増やします。

雨ブリジュラスやドラゴン軸には、メガフラエッテを攻撃役にします。オオニューラとゴリランダーのねこだまし、通常ボーマンダの威嚇でフラエッテが瞑想を積む時間を作り、ムーンフォースで相手の中心を倒すプランです。

イダイトウは、この二つの展開を補う削り役・終盤の処理役です。相手のオオニューラを倒してフラエッテを動かしやすくするほか、追い風下のおはかまいりやアクアジェットで試合を締めます。

## 基本選出と動かし方

### ボーマンダを通す

{{< selection lead="salamence,sneasler" back="kingambit,rillaboom" >}}

原案で多く選出された4体を、先発ボーマンダ＋オオニューラで追い風から展開する形です。相手に合わせて先発・後発を入れ替えます。

ボーマンダとオオニューラを並べたら、オオニューラのねこだましで相手を止め、ボーマンダが追い風を展開します。その後、ボーマンダのハイパーボイスとオオニューラの攻撃で削ります。鋼タイプにはかえんほうしゃ、ドドゲザンやフラエッテにはオオニューラの打点を通していきます。

相手の初手にライチュウやサーフゴーなどが来そうなら、ゴリランダーやドドゲザンを先に出し、ボーマンダを後ろに置く選出も使います。後発ボーマンダで威嚇を入れ、追い風を張ってから攻め直せるのが強みです。

終盤は、ゴリランダーのグラススライダーやドドゲザンのふいうちで、削れた相手を処理します。イダイトウの攻撃が通りやすい相手には4体のうち1体を入れ替え、おはかまいりで詰める形にします。

### フラエッテを通す

{{< selection lead="floette-eternal,rillaboom" back="sneasler,salamence" >}}

雨グソクに対する選出です。先発ゴリランダーのねこだましで相手を止め、フラエッテが瞑想を積みます。ゴリランダーのフィールド回復でHPを保ち、相手の物理攻撃には通常ボーマンダの威嚇を合わせます。

目標は、相手の主力をムーンフォースで倒せる状態を作ることです。特にブリジュラスには、瞑想からの高火力ムーンフォースで早く処理することを狙います。

グソクムシャが場にいるときは、通常ボーマンダの威嚇と、オオニューラ・ゴリランダーのねこだましで行動を抑え、その隣をフラエッテで倒していく形が基本です。オオニューラが重い相手にはイダイトウを合わせ、先に処理してからフラエッテを通します。

## メジャーな構築への選出

以下は原案の選出と立ち回りです。相性の表記は原著者の評価です。

### ライチュウスタン：微有利

{{< selection lead="rillaboom,kingambit" back="salamence,basculegion" >}}

ふいうちとグラススライダーでライチュウへ圧力をかけ、後発の追い風からイダイトウを通します。

相手には電気技が通りやすく見えるため、ライチュウから入ってくることが多い対面です。ボーマンダを警戒したミロカロス先発にも、ゴリランダーで対応できます。

ヒスイウインディを先発に出されたら、どちらかをボーマンダへ交代して威嚇を入れます。初手の2体を残しながら盤面を整え、最後は追い風下のイダイトウで詰めます。

### 雨グソク：五分

{{< selection lead="floette-eternal,rillaboom" back="sneasler,salamence" >}}

ゴリランダー・オオニューラのねこだましとボーマンダの威嚇でフラエッテを支え、瞑想から雨の攻撃役を突破します。

ペリッパー＋ブリジュラスから入られたら、ゴリランダーがペリッパーへねこだましを撃ち、フラエッテが瞑想。ゴリランダーとペリッパーの特性発動順から、素早さ関係も見ておきます。

グソクムシャ先発には、通常ボーマンダの威嚇を入れ、かえんほうしゃとムーンフォースを合わせます。あるいはオオニューラとゴリランダーのねこだましを使い回し、グソクムシャを止めながら隣を倒していきます。

### 晴れ＋雨：不利

{{< selection lead="salamence,sneasler" back="floette-eternal,basculegion" >}}

先にフシギバナを削り、後半のペリッパー＋ブリジュラスをフラエッテで詰める展開を目指します。

リザードン＋フシギバナへ耐性を持つボーマンダで入り、かえんほうしゃでフシギバナをアクアジェット圏内まで削ります。ボーマンダが眠ったら、オオニューラのねこだましとタスキで眠りターンを稼ぎます。

フシギバナの処理と、途中のブリジュラスへの交代読みが必要なため、難しい対面です。晴れ側を乗り切った後、瞑想フラエッテを残して雨側へ対応します。

### イエッサン＋サーナイト：有利

{{< selection lead="basculegion,kingambit" back="rillaboom,salamence" >}}

イエッサンを早く倒し、ゴリランダーでフィールドを取ることが目標です。

- **イエッサン＋グレンアルマ**なら、イダイトウで攻撃し、ドドゲザンをボーマンダへ交代します。
- **イエッサン＋サーナイト**なら、ドドゲザンで攻撃し、イダイトウをゴリランダーへ交代します。

相手の攻撃役に合わせて受け先を変え、フィールドを取り直し、ゴリランダーのねこだましやグラススライダー、ドドゲザンのふいうちを使える盤面を作ります。

### 雨滅び：不利

{{< selection lead="kingambit,sneasler" back="floette-eternal,basculegion" >}}

ドドゲザンでゲンガーへ圧力をかけ、オオニューラでガオガエン・ゴリランダーを攻撃します。ジャラランガにはフラエッテを残します。

防音ジャラランガを想定すると、ボーマンダのハイパーボイスが通らず、滅びのうたでも処理されません。フェアリー4倍弱点を突けるフラエッテを選ぶ理由になります。

苦しいのは、メガゲンガーのかげふみで交代を制限され、ジャラランガの起点を作られる展開です。ドドゲザンのアイアンヘッドとオオニューラのインファイトを集中させるなど、相手に自由な準備時間を与えない立ち回りを目指します。

見せ合いのゴリランダーがニョロトノ＋ラグラージを牽制するため、著者は相手の雨選出が少ないと見ています。

### 砂サイコ＋アーマーガア：有利

{{< selection lead="salamence,kingambit" back="rillaboom,basculegion" >}}

アーマーガアをかえんほうしゃで削り、後発のゴリランダーとイダイトウで詰めます。

こちらにアーマーガアが刺さっているため、相手は初手から出してくることが多いと想定します。ボーマンダを先発させて処理を進めつつ、隣のドドゲザンでバンギラス・ドリュウズ・ボーマンダ側の展開もケアします。

### プテラ・リザードン・ニンフィア：有利

{{< selection lead="sneasler,kingambit" back="salamence,basculegion" >}}

プテラ＋タスキのドドゲザンを想定し、オオニューラのねこだましをドドゲザンへ、ドドゲザンのアイアンヘッドをプテラへ合わせます。初手の展開を抑え、後発のボーマンダとイダイトウで攻め切るプランです。

相手の後発はリザードン・ガブリアス・ニンフィアが中心。ただし、リキキリンを選出されたときは、トリックルーム下でニンフィアが攻撃できる並びを作らせないことを重視します。

### バクーダトリル：微有利

{{< selection lead="floette-eternal,kingambit" back="rillaboom,basculegion" >}}

フラエッテでトリル役を起点に瞑想を積み、後発ゴリランダーのねこだましも使いながらトリルターンを稼ぎます。

2回目の瞑想に相手ドドゲザンを合わせられると苦しくなります。さらに積むか、攻撃へ移るかは、相手の交代を見ながら判断します。

バクーダには、ゴリランダーでフィールドを取りながらイダイトウのアクアジェットで圧力をかけます。

### カイリュースタン：微有利

{{< selection lead="basculegion,floette-eternal" back="kingambit,sneasler" >}}

相手のメガ枠はカイリューを想定し、アクアジェット＋ムーンフォースで初手から圧力をかけます。フラエッテを狙うオオニューラにも、イダイトウが強く動けます。

サーフゴーは後発ドドゲザンで対応し、オオニューラで終盤を処理します。

ハイパーボイスを通したい場合には、次の選出も使えます。

{{< selection lead="kingambit,basculegion" back="salamence,sneasler" >}}

先発のドドゲザンとイダイトウで削り、後発のボーマンダとオオニューラで詰める形です。

### クエスパトラ＋ライチュウ：有利

{{< selection lead="floette-eternal,sneasler" back="rillaboom,unknown" >}}

クエスパトラより先に瞑想を積み、後発ブリジュラスに備えます。

初手はオオニューラがクエスパトラへねこだましを撃ち、フラエッテは瞑想。次のターンはオオニューラをゴリランダーへ交代し、瞑想を続けます。

ライチュウXのアンコールを受けた場合も、瞑想を積み進める方針です。解除されるターンにゴリランダーかオオニューラのねこだましを合わせ、フラエッテが攻撃へ移り、積み回数の優位を使って突破します。

## 個別解説

実数値・能力ポイントはH/A/B/C/D/Sの順です。ここではりこ原案の型を紹介します。

### ボーマンダ

{{< pokemon "salamence" >}}

- **持ち物・特性・性格**：ボーマンダナイト／いかく（メガ後はスカイスキン）／ひかえめ
- **技**：ハイパーボイス／かえんほうしゃ／おいかぜ／まもる
- **通常時の実数値**：183 / 139 / 100 / 159 / 120 / 138
- **メガ後の実数値**：183 / 148 / 150 / 170 / 130 / 158
- **能力ポイント**：13 / 0 / 0 / 15 / 20 / 18

構築の主軸。最速ヒスイウインディを上回るS158を確保し、残りは火力と耐久に回しています。追い風を張るだけでなく、攻撃を受けながらハイパーボイスを複数回撃つための調整です。

かえんほうしゃは、ドドゲザン・サーフゴー・アーマーガアなどへの打点です。ねっぷうより命中が安定し、狙った相手を集中して削れます。原記事では、グラスフィールドの回復込みでもドドゲザンを2発で倒す火力を目安にしています。

フラエッテをメガシンカさせる試合では、通常のまま威嚇と追い風で支援します。天候構築やグソクムシャ入りに対して、フラエッテと一緒に選出する役割です。

### オオニューラ

{{< pokemon "sneasler" >}}

ムーンフォースを選んだ理由は、瞑想1回からブリジュラスを一撃で倒す火力を重視したためです。ドレインキッスで回復しながら何度も攻撃するより、相手を早く倒して被弾回数を減らすことを狙っています。

物理防御も厚く、くろたま山決勝ではグソクムシャのふいうちとオオニューラのフェイタルクローを耐えて勝利に貢献しました。回復はゴリランダーのフィールドで補います。

序盤は耐久を使ってウェーブタックルで削り、終盤はおはかまいりとアクアジェットで処理します。猫を受けずに動けるため、追い風との相性もよい枠です。

フラエッテを狙うオオニューラに強く、リザードン・グレンアルマ・バクーダなどにも打点を持ちます。ヒスイウインディには、アクアジェットとボーマンダのハイパーボイスを合わせる動きも使います。

原案のカシブのみはゴースト技への耐久を補う持ち物です。アレンジ版ではナモのみとなり、ドドゲザンやグソクムシャの前でも攻撃しやすくなりました。著者も、最終的にはナモのみを推奨しています。

## 構築経緯と環境への対応

### 命中安定と耐久を出発点にする

原案を作る前の環境では、いわなだれやねむりごなが長く使われていました。著者は命中不安を減らし、耐久に寄せて不利な乱数に負けにくい構築を目指しました。

そこで、新環境で追加されたメガボーマンダに着目。命中が安定する高火力全体技、高い耐久と素早さ、グソクムシャへの強さを評価して採用しました。

技はハイパーボイス・おいかぜ・まもるを先に決め、最後の枠を比較しています。りゅうせいぐんは同速勝負と命中の不安、すてみタックルは反動が気になり、ねっぷうも命中と対ドドゲザンの火力を理由に外しました。最後に残ったのがかえんほうしゃです。

### 苦手な相手を補完する

まず、ボーマンダが苦手なフェアリー・鋼を攻撃でき、猫＋追い風も使えるオオニューラを採用しました。

次に、イエッサン＋サーナイト・サーフゴー・メガライチュウYへ対応するため、ドドゲザンとゴリランダーを追加。ゴースト・エスパーへの打点、サイコフィールドの解除、先制技、回復が揃い、汎用性の高い4体ができました。

残る課題はペリブリとドラゴン軸。ここへ瞑想フラエッテを加え、オオニューラ・ゴリランダーのねこだましと、グラスフィールド回復を使う第二の勝ち筋を用意しました。

最後に、フラエッテ選出で重くなりやすいオオニューラやウルガモス、さらに晴れ・バクーダ・バンドリへ対応するイダイトウを加えて6体が完成しました。

## Brisbane・GC向けのアレンジ

### 技と持ち物の変更

Newcon氏・すいか氏・リンヤ氏は、BrisbaneのOTS環境を想定して原案を調整しました。

| ポケモン | 原案 | アレンジ版 |
|---|---|---|
| オオニューラ | どくづき | フェイタルクロー |
| ドドゲザン | けたぐり | まもる |
| イダイトウ♂ | カシブのみ | ナモのみ |

サイコフィールドとトリルが多いと予想し、ドドゲザンをまもる持ちへ変更しました。猫＋攻撃の集中を防ぎ、効果ターンを稼げるようにするためです。

けたぐりを失ったことで相手ドドゲザンへの対応が減る分は、ナモのみイダイトウで補います。ゲンガーは少なそう、バンドリは使われそうという環境予測にも合う変更でした。

例えば相手がオオニューラ＋ドドゲザンを並べた場面でも、ナモのみがあればイダイトウでオオニューラを攻撃しやすくなります。フラエッテを通すための処理役としても動かしやすくなる変更です。

### 火力と行動順を調整する

ゴリランダーは、原案の耐久重視から攻撃実数値187へ変更。グラススライダーと10まんばりきで倒せる範囲を広げました。

素早さはイダイトウより1低くしています。持久力ブリジュラスに対し、おはかまいりを先に当てて大きく削り、防御が上がった後に10まんばりきを当てる順序を作るためです。

すいか/S版では、この順序を保ったまま両方を準速ペリッパーより速くしています。

| ポケモン | Newcon版のS | すいか/S版のS |
|---|---:|---:|
| イダイトウ♂ | 114 | 119 |
| ゴリランダー | 113 | 118 |

ドドゲザンはS70の遅めの調整となり、まもると合わせてトリルへの対応を強めています。一方、原案のけたぐりにもバンギラスやドドゲザンミラーを処理する役割があり、著者たちは大会環境に応じて技を選んでいます。
